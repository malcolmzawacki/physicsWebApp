# Series And Parallel Circuits Scope

_Created: 2026-03-31_

This note defines the first-pass scope for a current electricity activity focused on simple series circuits and two-resistor parallel circuits.

## Instructional Goal

Students should be able to:

- identify whether two resistors are in series or parallel
- calculate equivalent resistance for a series pair
- calculate total current in a simple series loop
- calculate equivalent resistance for a two-resistor parallel circuit
- calculate branch current in a two-resistor parallel circuit

## Initial Scope

Included:

- two-resistor series equivalent resistance
- total current in a two-resistor series circuit
- two-resistor parallel equivalent resistance
- branch current in a two-resistor parallel circuit
- the same side-by-side layout pattern used in the first current electricity activity

Deferred:

- three-resistor parallel reduction
- mixed series-parallel reduction
- total current in parallel from equivalent resistance
- branch power calculations

## Modeling Assumptions

- Batteries are ideal voltage sources.
- Wires are ideal with negligible resistance.
- Resistors obey Ohm's law exactly.
- Parallel examples are limited to two resistors for now so the equivalent resistance step stays classroom-friendly.
- The generator uses curated value sets so equivalent resistances and currents stay reasonably clean.
